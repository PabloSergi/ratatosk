Every channel becomes its own scraper. Behind one, a group that goes quiet or throws you out is covered by the ones that still answer, and the card looks healthy while you lose a source.

A channel decides nothing about what a message is: postings, CVs, someone selling accounts and someone saying “up” arrive through the same pipe. Say what you are after and the model reads a sample of real messages and writes the rule that separates them — kept only if it demonstrably does. After that it runs as plain patterns: no model, no cost per message.

Keys for machines

A schedule in n8n, a cron, somebody else’s script — they need a credential that outlives a login. Your own token expires in a month; a key does not, is named so you know a year later what it was for, and is revoked on its own without disturbing the others. See docs/n8n.md for the exact setup.

Model connections

Two different jobs. Builds writes a scraper or a rule — once, carefully, and worth a good model. Runs is the second opinion on borderline rows: it happens on every run, forever, so it wants the cheapest thing that can read. One connection can do both; two usually cost less.

Add a connection

  1. Pick a provider and open its key page — the link appears once you choose one.
  2. Create a key there and paste it below. It is stored for your account only, shown afterwards as its last four characters, and deletable here.
  3. Choose a model. The list is read from that provider, not compiled in.

Telegram accounts

Connect an account

Public channels need none of this — build a scraper for t.me/s/<channel> like any other page. Groups have no web page at all, so reading one means being a member, which means a Telegram account. Connect as many as you like; a scraper names the one it reads with.

  1. Get an api_id and an api_hash

    Open my.telegram.org → log in with the phone number of that account → API development tools. Fill App title and Short name with anything (for example ratatosk) and press Create application. The page then shows App api_id — a number — and App api_hash — 32 characters.

  2. Type the code Telegram just sent

    It arrives inside Telegram, from the account called “Telegram” — not by SMS, unless no other device is signed in. If that account has two-step verification, its password goes in the second field; otherwise leave it empty.

  3. Build a scraper with it

    Scrapers are made in Scrapers → telegram, where you choose which account reads which channels.
